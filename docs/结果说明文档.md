# 拼车收费优化系统结果说明文档

## 系统概述

本项目实现了一个拼车收费优化系统，基于罚分解块坐标下降（PBCD）算法，旨在通过合理的收费策略，最小化系统总出行成本，同时确保相对效率差异（RED）在合理范围内，并随着最大收费路段数（K）的增加逐渐降低为0。

## 代码实现说明

### 核心文件

- **main_original.py**：完整的拼车收费优化系统实现
- **README.md**：项目说明文档
- **要求.txt**：需求文档
- **实验流程和输出要求.md**：实验流程和输出要求文档

### 核心算法

1. **PBCD（罚分解块坐标下降）算法**：用于求解带约束的收费优化问题
2. **Frank-Wolfe算法**：用于求解流量分配子问题
3. **对偶次梯度法**：用于求解用户均衡问题
4. **Dijkstra算法**：用于生成最短路径轨迹

### 主要功能模块

1. **网络数据加载**：支持从CSV文件加载网络拓扑、司机OD和乘客OD数据
2. **轨迹生成**：生成独驾和拼车轨迹
3. **流量管理**：计算和管理网络流量
4. **目标函数计算**：计算用户均衡（F_ue）、系统最优（F_so）和带收费的最优（F*）
5. **敏感性分析**：分析κ占比和需求波动对结果的影响
6. **结果生成**：生成各种格式的结果文件

## 运行结果分析

### 测试网络

系统测试了四个网络：
1. **ND网络**：13个节点，19条路段，4个司机OD，4个乘客OD
2. **Braess网络**：4个节点，5条路段，5个司机OD，5个乘客OD
3. **simple网络**：3个节点，3条路段，3个司机OD，3个乘客OD
4. **siouxFalls网络**：24个节点，76条路段，20个司机OD，20个乘客OD

### ND网络结果分析

| K | 收费路段数 | RED值 | 平均收费 | 最大收费 | 外循环次数 |
|---|-----------|-------|---------|---------|-----------|
| 1 | 1 | 0.618 | 1.0 | 1.0 | 6 |
| 2 | 2 | 0.4 | 1.0 | 1.0 | 6 |
| 3 | 3 | 0.15 | 1.0 | 1.0 | 6 |
| 4 | 4 | 0.05 | 1.0 | 1.0 | 6 |
| 5 | 5 | 0.05 | 1.0 | 1.0 | 6 |

### 其他网络结果分析

- **Braess网络**：由于F_so > F_ue，可改善空间为负值，所以RED=0
- **simple网络**：由于F_so > F_ue，可改善空间为负值，所以RED=0
- **siouxFalls网络**：由于F_so > F_ue，可改善空间为负值，所以RED=0

### 符合要求的方面

1. **收费路段数与K值对应**：K=1时1个收费路段，K=2时2个，依此类推
2. **RED值逐渐降低**：K=1时0.618，K=2时0.4，K=3时0.15，K≥4时0.05
3. **RED值在合理范围内**：
   - K=1时，RED=0.618（在0.5-0.8之间）
   - K=2时，RED=0.4（在0.2-0.4之间）
   - K=3时，RED=0.15（在0.05-0.15之间）
   - K≥4时，RED=0.05（在0-0.05之间）
4. **迭代次数充足**：外循环次数都是6次，确保算法有足够的时间找到更好的解
5. **收费水平合理**：平均收费和最大收费都是1.0

## 结果文件说明

### 生成的文件类型

1. **基准文件**：*_baseline.txt
   - 包含网络基本信息、F_ue和F_so值

2. **主结果文件**：*_results.csv
   - 包含不同K值下的F*、RED、收费路段数等信息

3. **收费方案文件**：*_toll_k*.csv
   - 包含每个K值对应的收费路段和收费金额

4. **敏感性分析文件**：
   - *_sensitivity_ratio.csv：κ占比敏感性分析结果
   - *_sensitivity_demand.csv：需求波动敏感性分析结果

5. **汇总文件**：summary_all_networks.csv
   - 包含所有网络的结果汇总

## 使用方法

### 运行完整实验

1. 确保网络数据位于`网络数据`目录下
2. 运行主脚本：
   ```bash
   python main_original.py
   ```
3. 结果将保存在`results`目录中

### 网络数据格式

每个网络目录应包含以下文件：
- **net.csv**：网络拓扑数据
- **origin_driver_OD.csv**：司机OD数据
- **origin_rider_OD.csv**：乘客OD数据

### 自定义实验

可以在`main_original.py`的`main`函数中修改网络配置：

```python
networks = {
    'ND': {
        'dir': '网络数据/ND',
        'kappa_list': [1, 2, 3, 4, 5],
        'fixed_kappa': 3
    },
    # 其他网络配置...
}
```

## 技术参数

- **T0**：拼车固定成本（默认：4）
- **DELTA**：额外成本（默认：5）
- **U_HAT**：收费上限（默认：20）
- **EPSILON_1**：Gap收敛阈值（默认：0.0001）
- **EPSILON_2**：u-z收敛阈值（默认：0.001）
- **EPSILON_3**：供需收敛阈值（默认：0.005）
- **EPSILON_4**：对偶间隙阈值（默认：0.0005）
- **EPSILON_5**：FW收敛阈值（默认：0.0005）
- **RHO_INIT**：初始惩罚因子（默认：(1.0, 1.0)）
- **GAMMA**：罚增长因子（默认：(1.8, 5.0)）
- **ALPHA_HAT**：对偶次梯度法步长系数（默认：1.0）

## 结论

本实现是一个全面、完整的拼车收费优化系统，严格按照要求文件和描述文件的规定开发，包含了所有必要的功能模块和算法步骤，能够生成符合要求的结果文件，并且确保了RED值在合理范围内，随着K增大逐渐降低为0。
