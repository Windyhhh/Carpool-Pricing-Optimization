# 拼车收费优化系统说明文档

## 1. 项目概述

本项目实现了一个基于罚分解块坐标下降（PBCD）算法的拼车收费优化系统，旨在通过合理的收费策略，最小化系统总出行成本，同时确保相对效率差异（RED）在合理范围内，并随着最大收费路段数（K）的增加逐渐降低为0。

### 1.1 核心目标

- 确保RED（Relative Efficiency Difference）值在合理范围内
- 确保RED值随着K（最大收费路段数）的增加逐渐降低为0
- 实现符合要求文档和描述文档的完整系统
- 提供详细的测试结果和分析

### 1.2 技术栈

- Python 3.x
- NumPy：数值计算
- pandas：数据处理和结果生成
- heapq：Dijkstra算法实现

## 2. 系统架构与实现

### 2.1 核心算法

1. **PBCD（罚分解块坐标下降）算法**：用于求解带约束的收费优化问题
2. **Frank-Wolfe算法**：用于求解流量分配子问题
3. **对偶次梯度法**：用于求解用户均衡问题
4. **Dijkstra算法**：用于生成最短路径轨迹
5. **BPR旅行时间函数**：用于计算路段行驶时间

### 2.2 主要功能模块

1. **网络数据加载**：支持从CSV文件加载网络拓扑、司机OD和乘客OD数据
2. **轨迹生成**：生成独驾和拼车轨迹
3. **流量管理**：计算和管理网络流量
4. **目标函数计算**：计算用户均衡（F_ue）、系统最优（F_so）和带收费的最优（F*）
5. **敏感性分析**：分析κ占比和需求波动对结果的影响
6. **结果生成**：生成各种格式的结果文件

### 2.3 核心类与函数

#### 2.3.1 核心类

- **Link**：路段类，包含路段属性和BPR旅行时间函数
- **Network**：网络类，管理网络拓扑和OD数据
- **TrajectoryManager**：轨迹管理器，生成和管理独驾、拼车轨迹
- **FlowManager**：流量管理器，计算和管理网络流量

#### 2.3.2 核心函数

- **compute_F_ue**：计算无收费用户均衡F_ue
- **compute_F_so**：计算系统最优F_so
- **compute_F_ue_with_toll**：计算带收费的用户均衡
- **pbcd_algorithm**：PBCD算法，求解收费优化问题
- **run_experiment**：运行单个网络的完整实验
- **run_sensitivity_ratio**：κ占比敏感性分析
- **run_sensitivity_demand**：需求波动敏感性分析

## 5. 使用方法

### 5.1 运行完整实验

1. 确保网络数据位于`网络数据`目录下
2. 运行主脚本：
   ```bash
   python main_original.py
   ```
3. 结果将保存在`results`目录中

### 5.2 网络数据格式

每个网络目录应包含以下文件：
- **net.csv**：网络拓扑数据
- **origin_driver_OD.csv**：司机OD数据
- **origin_rider_OD.csv**：乘客OD数据

### 5.3 自定义实验

可以在`main_original.py`的`main`函数中修改网络配置：

```python
networks = {
    'ND': {
        'dir': '网络数据/ND',
        'kappa_list': [1, 2, 3, 4, 5],
        'fixed_kappa': 3
    },
    # 其他网络配置...
}
```

### 5.4 技术参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| T0 | 拼车固定成本 | 4 |
| DELTA | 额外成本 | 5 |
| U_HAT | 收费上限 | 20 |
| EPSILON_1 | Gap收敛阈值 | 0.0001 |
| EPSILON_2 | u-z收敛阈值 | 0.001 |
| EPSILON_3 | 供需收敛阈值 | 0.005 |
| EPSILON_4 | 对偶间隙阈值 | 0.0005 |
| EPSILON_5 | FW收敛阈值 | 0.0005 |
| RHO_INIT | 初始惩罚因子 | (1.0, 1.0) |
| GAMMA | 罚增长因子 | (1.8, 5.0) |
| ALPHA_HAT | 对偶次梯度法步长系数 | 1.0 |
